# Proyecto de Estadística Bayesiana - Ciencia de Datos (4° Semestre)
**Universidad Externado de Colombia**

## 🎯 Objetivo del Proyecto
Este proyecto tiene como fin aplicar los conceptos avanzados de Inferencia Bayesiana vistos en clase sobre un caso de estudio real basado en nuestra base de datos (`02_datos/`). Buscamos realizar un análisis riguroso, analítico y profundo, implementando distribuciones a priori informativas/no informativas, verosimilitudes, cálculo analítico o aproximado de distribuciones posteriores, y análisis de distribuciones predictivas posteriores.

## 📁 Contenido de la Carpeta
- `01_teoria/`: Contiene los resúmenes teóricos y modelos vistos en clase (Beta-Binomial, Gamma-Poisson, Normal-Normal, Dirichlet-Multinomial, etc.).
- `02_datos/`: Base de datos oficial sobre la cual se ejecutará el análisis estadístico.
- `03_entregas/`: Historial de avances documentados en las entregas previas (`entrega_1.pdf`, `entrega_2.pdf`).

## ⚙️ Directrices para el Asistente
1. **Nivel Académico:** Estudiante de pregrado en Ciencia de Datos de 4to semestre. Se espera rigor matemático, notación formal y explicaciones profundas de la intuición bayesiana.
2. **Enfoque Analítico:** No te limites a calcular de forma mecánica. Explica el rol de los hiperparámetros (como los tamaños de muestra equivalentes $a_0 + b_0$), justifica la elección de las familias conjugadas y analiza la incertidumbre mediante distribuciones predictivas posteriores.
