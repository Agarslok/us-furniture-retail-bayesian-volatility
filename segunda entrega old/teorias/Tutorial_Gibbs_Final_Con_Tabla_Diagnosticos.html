1. ¿Qué es el muestreo de Gibbs?

Gibbs es un algoritmo MCMC que actualiza cada parámetro a partir de su distribución condicional completa mientras mantiene fijos temporalmente los demás.

θ₁⁽ᵗ⁾ ~ p(θ₁ | θ₂⁽ᵗ⁻¹⁾,y)
θ₂⁽ᵗ⁾ ~ p(θ₂ | θ₁⁽ᵗ⁾,y)
Movimiento: actualización de un parámetro. Barrido: actualización de todos los parámetros una vez. Gibbs no busca un único valor óptimo; genera una muestra de la posterior.

2. Modelo conjugado Beta-Binomial

En un peaje ubicado en una salida de Bogotá se observaron 1.000 vehículos: 80 evadieron y 920 pagaron. Sea θ la proporción verdadera de evasión en condiciones comparables.

Datos

n=1.000, y=80
Observado: 8 %

Modelo

Y|θ ~ Binomial(n,θ)
θ ~ Beta(2,18)

Posterior

θ|y ~ Beta(82,938)
Media posterior
8,04 %
Intervalo creíble 95 %
6,45 % a 9,78 %
P(θ>10 %|y)
1,44 %

La media posterior de 8,04 % equivale a esperar alrededor de 80 evasores por cada 1.000 vehículos en condiciones comparables. La previa tiene poco peso frente a los 1.000 datos.

Aclaración: este modelo no necesita Gibbs, pues la posterior Beta se conoce exactamente. Sirve como actualización bayesiana verificable.

4. Ejemplo en el que sí se usa Gibbs

Porcentajes diarios observados durante diez días:

7,4; 8,1; 7,8; 9,0; 8,5; 7,2; 8,8; 7,9; 8,3; 7,6

Se estiman μ, la evasión media diaria, y σ², la variabilidad entre días:

yᵢ|μ,σ² ~ Normal(μ,σ²)
μ|σ² ~ Normal(μ₀,σ²/κ₀)
σ² ~ Inversa-Gamma(α₀,β₀)

Valores didácticos: μ₀=8, κ₀=1, α₀=2 y β₀=1. Cada barrido actualiza primero μ|σ²,y y después σ²|μ,y. No se necesita Metropolis-Hastings.

5. Diagnósticos fundamentales

Burn-in

Tramo inicial descartado para reducir la influencia del punto de partida. Se evalúa junto con trazas y múltiples cadenas.

Gráfica de trazas

Debe formar una banda estable, sin tendencia persistente ni cadenas atrapadas.

Autocorrelación y ACF

La autocorrelación es la dependencia para un rezago; la ACF reúne las autocorrelaciones de varios rezagos.

ESS

Aproxima cuántas muestras independientes equivalen a la cadena correlacionada.

R-hat

Compara variación entre y dentro de varias cadenas. Valores cercanos a 1 son deseables.

MCSE

Cuantifica el error numérico debido a usar una simulación finita.

¿Cómo debería comportarse una traza?

Traza estable

Fluctúa alrededor de una región constante.

Traza con tendencia

Sugiere calentamiento incompleto.

Alta persistencia

Se mueve lentamente; ACF alta y ESS menor.

Cambio de régimen

Puede indicar exploración incompleta.

6. ¿Qué hacer con los resultados?

6.1 Inferencia sobre la media

La evasión media diaria se estima en 8,06 %, con intervalo creíble del 95 % entre 7,67 % y 8,45 %. La desviación diaria se estima en 0,64 puntos porcentuales.

6.3 Convertir la tasa en evasores

10.000 × 0,0806 ≈ 806 evasores

El intervalo creíble de la media equivale aproximadamente a 767–845 evasores por cada 10.000 vehículos. Esto no es todavía un intervalo predictivo para un día específico.

El intervalo predictivo es más amplio porque incorpora la variación entre días.

6.5 Proyectar evasores y valor tarifario

Para 10.000 vehículos se simula primero una tasa futura y después un conteo binomial. Si se multiplica el conteo por una tarifa, se obtiene un valor tarifario asociado, no automáticamente una pérdida contable.

6.6 Detectar una jornada inusual

La probabilidad de una tasa futura igual o superior a 10,2 % es aproximadamente 0,22 %. Una observación así justificaría revisión operativa, pero no demuestra por sí sola fraude, incumplimiento o error de recaudo.

6.7 Comparar con una meta contractual

Supóngase, solo con fines didácticos, una meta de mantener la evasión media por debajo de 8,5 %.

Interpretación: existe evidencia favorable de que la media está por debajo de 8,5 %. Sin embargo, una jornada particular puede superar el umbral debido a la variación diaria.

No confundir: mu_post < 8.5 evalúa una meta sobre la media general; tasa_futura < 8.5 evalúa una jornada futura. Antes de una conclusión contractual real deben verificarse la definición del indicador, periodo, exclusiones, datos y reglas del contrato. El 8,5 % es ilustrativo.

7. Código reproducible en R

set.seed(123)
y <- c(7.4,8.1,7.8,9.0,8.5,7.2,8.8,7.9,8.3,7.6)
n <- length(y); mu0 <- 8; kappa0 <- 1; alpha0 <- 2; beta0 <- 1
S <- 10000; burn_in <- 2000
mu <- sigma2 <- numeric(S); mu[1] <- 8; sigma2[1] <- 1
kappa_n <- kappa0+n
mu_n <- (kappa0*mu0+n*mean(y))/kappa_n
for(t in 2:S){
 mu[t] <- rnorm(1,mu_n,sqrt(sigma2[t-1]/kappa_n))
 a <- alpha0+(n+1)/2
 b <- beta0+.5*sum((y-mu[t])^2)+.5*kappa0*(mu[t]-mu0)^2
 sigma2[t] <- 1/rgamma(1,shape=a,rate=b)
}
keep <- (burn_in+1):S
mu_post <- mu[keep]; sigma2_post <- sigma2[keep]
quantile(mu_post,c(.025,.5,.975)); mean(mu_post)

# Diagnósticos
par(mfrow=c(2,2)); plot(mu,type="l"); plot(sigma2,type="l")
acf(mu_post); acf(sigma2_post); par(mfrow=c(1,1))
library(coda)
effectiveSize(mcmc(cbind(mu_post,sigma2_post)))

# Probabilidades y meta
mean(mu_post>8); mean(mu_post>8.5); mean(mu_post<8.5)

# Predicción de tasa futura y evasores
set.seed(456)
tasa_futura <- rnorm(length(mu_post),mu_post,sqrt(sigma2_post))
tasa_futura <- pmin(pmax(tasa_futura,0),100)
quantile(tasa_futura,c(.025,.5,.975))
mean(tasa_futura>9); mean(tasa_futura>=10.2)
N_futuro <- 10000
evasores <- rbinom(length(tasa_futura),N_futuro,tasa_futura/100)
quantile(evasores,c(.025,.5,.975))

# Meta contractual ilustrativa
meta <- 8.5
mean(mu_post<meta)          # meta sobre la media
mean(tasa_futura<meta)      # jornada futura
